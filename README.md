# 拓咸助手 · MakerWorld → 闲鱼 3D 打印半自动发布系统

一个**本地运行**的浏览器扩展 + Python 工具链：在 MakerWorld 选好模型后一键采集资料，AI 润色文案，
再半自动填写闲鱼发布页。**发布动作始终由人工检查后手动点击**，不做全自动发布，也不绕过平台验证。

> 关键词：MakerWorld 采集 · 闲鱼发布 · Manifest V3 · DeepSeek · 半自动化 · 3D 打印

## 这是什么 / 不是什么

**是**：

- 两个 Manifest V3 浏览器扩展：MakerWorld 一键采集、闲鱼发布页辅助填表
- 一个只监听 `127.0.0.1` 的本地 AI 转发服务（保护 DeepSeek API Key）
- 一套 Python 脚本：下载搬运、图片转 PNG、信息提取、草稿生成
- 一套 45 项自动化自测（Node + Python），改代码后可以快速回归

**不是**：

- 不是全自动铺货/发布机器人（不会点发布按钮）
- 不会绕过闲鱼的风控、手机验证或平台规则
- 不判断模型授权：**商用、改名、使用作者图片前必须自行确认授权**

**仓库不包含**：任何 3D 模型文件、采集到的图片/页面截图、个人采集数据。原因见 [版权与合规](#版权与合规)。

## 工作流

```text
┌─────────────────────────────┐
│ MakerWorld 模型详情页        │
│ 鼠标悬停打印配置 → Alt+M     │
└──────────────┬──────────────┘
               │ 采集扩展（MV3）
               ▼
   浏览器下载目录/模型发布信息采集/<时间戳>/
   ├── model_<id>.json        ← 标题/简介/耗材/时长/许可/图片直链
   ├── screenshot_visible.png
   └── images/image_01..10    ← 按设计图去重，最多 10 张
               │ move_to_storage.py（搬运 + 补图 + 转 PNG）
               ▼
        信息储存/<时间戳>/
               │ extract_model_info.py（可选）
               ▼
   .extracted.json / .draft.md ← 结构化字段 + IP 风险提示
               │ 闲鱼发布助手（MV3 面板）
               ▼
   本地 AI 服务 127.0.0.1:8765 ──► DeepSeek（deepseek-flash）
               │ 读草稿 → AI 润色 → 扫描 17 个字段 → 填写表单
               ▼
        人工检查页面 → 手动点击「发布」
```

## 功能清单

### 1) MakerWorld 一键采集（`3D模型一键采集扩展/`）

- `Alt+M` 一次采集，**只触发一次**（页面快捷键与扩展命令做了合并）
- 保存 `model_<id>.json` + 当前页面截图 + 最多 10 张图片
- 图片按「设计图」去重：同一张图的 `w_1200 / w_1000 / w_400` 只留最高清版本
- 耗材克数 / 打印时长做范围校验，不会把模型 ID 误识别成 `xxxx h`
- 只允许在 MakerWorld 页面采集；非模型详情页不会保存（隐私保护）
- 等待下载真正完成才计成功，图片下载失败会如实报告

### 2) 下载搬运（`move_to_storage.py`）

- 等待下载稳定（无 `.crdownload` 且 5 秒无新文件）后再搬运
- 缺图时按 JSON 里的图片直链补下载（带 Referer、重试、大小上限）
- `webp/jpg` 统一转 PNG；同名文件不覆盖、保留两份
- 支持 `--watch` / `--repair` / `--source` / `--target` 与环境变量

### 3) 信息提取（`工具脚本/`）

- `extract_model_info.py`：标题清洗、作者/分类/打印配置/耗材/时长/标签、IP 与授权风险提示
- `generate_draft.py`：不调用 AI，快速生成初版闲鱼草稿

### 4) 闲鱼发布助手（`拓咸助手/咸鱼自动发布3d打印模型系统/闲鱼发布助手/`）

- 读取采集 JSON 或提取后的 `.extracted.json`，自动清洗平台标题后缀、HTML 实体、`为我助力` 段
- AI 润色标题/描述/价格，支持可编辑的「AI 文案规则」
- 扫描发布页 17 个字段；一键选择「其他闲置」；填写标题/描述/价格/原价/成色/发货/图片
- 原生 `<select>` 直接赋值，自定义下拉在展开层内查找，减少点错
- 只在闲鱼域名注入面板；不会自动点击发布

### 5) 本地 AI 服务（`本地AI服务/local_ai_server.py`）

- 只监听 `127.0.0.1`，API Key 不进入网页
- 只接受浏览器扩展来源（`X-XY-Client` 请求头 + 拒绝网页/`null` Origin）
- 模型 `deepseek-flash`，关闭思考模式（更快更省），JSON 输出 + 空内容自动重试
- 附带一键设置/取消开机自启的脚本

## 快速开始（Windows）

### 0. 环境

- Windows 10/11 + Edge 或 Chrome（支持 Manifest V3）
- Python 3.10+，并安装依赖：

```powershell
python -m pip install -r "拓咸助手/咸鱼自动发布3d打印模型系统/requirements.txt"
```

### 1. 启动本地 AI 服务

```text
双击 拓咸助手\咸鱼自动发布3d打印模型系统\本地AI服务\启动闲鱼AI本地服务.bat
```

看到 `闲鱼 AI 本地服务 v0.6.0: http://127.0.0.1:8765` 即成功。
想开机自启：双击同目录的 `设置开机自启.bat`（取消：`取消开机自启.bat`）。

### 2. 加载两个扩展

打开 `edge://extensions/`（Chrome 为 `chrome://extensions/`）→ 打开「开发人员模式」→「加载解压缩的扩展」：

```text
采集扩展：    <仓库根目录>\3D模型一键采集扩展
闲鱼发布助手：<仓库根目录>\拓咸助手\咸鱼自动发布3d打印模型系统\闲鱼发布助手
```

> 要选到能直接看到 `manifest.json` 的文件夹。

### 3. 采集

1. 打开 MakerWorld 模型详情页
2. 鼠标悬停在打印配置卡片上，等出现 `PLA | xxx g` 浮层
3. 按 `Alt + M`
4. 结果进入浏览器下载目录 → 双击采集扩展目录里的 `启动自动搬运.bat` 或 `搬运一次.bat`

### 4. 润色 + 填表

1. 打开闲鱼网页版发布页，点扩展图标打开面板
2. 「AI 设置」填 DeepSeek API Key（服务端配了 `DEEPSEEK_API_KEY` 环境变量时可不填）→ 保存 → 测试连接
3. 「草稿」读取采集 JSON（或 `.extracted.json`）→ AI 润色 → 人工确认提示
4. 「表单」选图片 → 扫描表单（应显示「已识别 N/17 个字段」）→ 填写整张表单
5. **人工检查页面后手动点击发布**

## 配置项

| 配置 | 位置 | 说明 |
| --- | --- | --- |
| DeepSeek API Key | 面板「AI 设置」或环境变量 `DEEPSEEK_API_KEY` | 只存在本地浏览器存储 / 服务端环境变量 |
| 本地服务地址 | 面板「AI 设置」 | 默认 `http://127.0.0.1:8765/polish` |
| `XY_AI_PORT` | 环境变量 | 本地服务端口，默认 8765 |
| `XY_DOWNLOAD_DIR` | 环境变量 | 浏览器下载目录，默认 `%USERPROFILE%\Downloads` |
| `XY_COLLECT_TARGET` | 环境变量 | 信息储存目录，默认脚本同级 `信息储存` |

AI 文案规则可在面板里直接写中文，例如「保留原模型/IP/作者名；不虚构材质尺寸；不加官方/正版声明」。

## 安全与隐私设计

- **只采模型页**：采集扩展校验 MakerWorld 域名 + `/models/数字`；非模型页不注入、不保存
- **只监听本机**：AI 服务绑定 `127.0.0.1`；网页与沙箱 iframe（`Origin: null`）调用一律 403
- **不泄露 Key**：Key 不进入网页 DOM，也不写入日志；仓库内没有任何 Key
- **人工发布**：不自动点击发布按钮，不绕过验证码/手机验证
- **数据最小化**：仓库不包含采集到的页面正文、截图、第三方图片和 3D 模型文件

若发现安全问题，请开 Issue 说明复现步骤（不要附真实 Key 或他人隐私数据）。

## 已知限制

- MakerWorld / 闲鱼的页面结构由平台控制，改版后可能需要更新选择器（代码里已留注释）。
- 浏览器扩展无法直接读取本地 `信息储存/images` 目录，选图仍需在面板手动选择。
- 自动测试使用 DOM mock 与纯 Python 逻辑，不能完全替代真实浏览器端到端验证。
- 文案模型输出仍需人工检查：价格、授权、尺寸、库存等信息不会被自动核实。
- 两份采集扩展代码（根目录与项目内 `采集扩展/`）需要同步维护，脚本里有 SHA256 一致性检查的习惯建议。
