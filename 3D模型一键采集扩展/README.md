# 3D模型一键采集扩展

## 当前版本 v0.9.0-10图

这个版本会保存：

- `model_模型ID.json`（标题/简介/耗材/时长/打印配置/许可/图片直链等）
- `screenshot_visible.png`
- `images/image_01.xxx` 到最多 `image_10.xxx`

### v0.9.0 改了什么

- **Alt+M 只采集一次**（旧版页面快捷键和扩展快捷键会各触发一次，生成两个文件夹）
- **图片按设计图去重**：同一张图的 `w_1200 / w_1000 / w_400` 只留最高清版本，不再把重复图传到闲鱼
- **打印时长/耗材克数不再误识别**：`494293576\nh`、`703h`、`3M` 这类垃圾值会被过滤
- **标题自动清洗**：去掉 ` - 免费 3D 打印模型 - MakerWorld` 后缀
- 提示条显示耗材/时长/图片成功数量/失败项；先截图再下载图片
- `collector_version` 与实际版本统一为 `0.9.0`

## 使用方式

1. 扩展页重新加载扩展。
2. 刷新 MakerWorld 页面。
3. 鼠标停在打印配置卡片上，让 `PLA | xxx g` 浮层出现。
4. 按 `Alt + M`（只按一次）。

## 下载结果的搬运

浏览器会先把文件放进下载目录，再由 `move_to_storage.py` 搬到 `信息储存\`：

```text
双击 搬运一次.bat            搬一次，并补一次历史缺图
双击 启动自动搬运.bat        常驻监控（默认每 3 秒）
python move_to_storage.py --repair
python move_to_storage.py --source D:\Downloads\模型发布信息采集 --target E:\数据\信息储存
```

可选环境变量：`XY_DOWNLOAD_DIR`（浏览器下载目录）、`XY_COLLECT_TARGET`（信息储存目录）。
搬运错误会写入 `信息储存\_搬运错误.log`。

详细说明见 ..\拓咸助手\咸鱼自动发布3d打印模型系统\使用规范.md 第 3、7 节，以及同目录的《修复说明.md》。
