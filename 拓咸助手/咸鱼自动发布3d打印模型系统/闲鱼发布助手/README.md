# 闲鱼 3D 模型发布助手 v0.8.0

一个浏览器扩展：读取 3D 模型草稿 JSON，调用 DeepSeek 润色文案，再半自动填写闲鱼网页发布表单。

## 功能

- 读取采集 JSON / `extract_model_info.py` 生成的 `.extracted.json`
- 自动清洗 MakerWorld 标题后缀、HTML 实体、`为我助力` 推广段
- AI 润色标题、描述、价格（DeepSeek `deepseek-flash`，关闭思考模式，更快更省）
- AI 文案规则可编辑、可恢复默认
- 扫描闲鱼发布页字段（标题、描述、分类、品牌、成色、价格、发货等）
- 自动选择“其他闲置”分类（仅点击网页真实存在的选项）
- 填入标题 / 描述 / 价格 / 原价 / 成色 / 发货方式 / 图片
- 不自动点击发布按钮，发布前人工确认

## v0.8.0 修复

- **修复「扫描表单 / 填写整张表单」必报错**：旧代码 `const scan = scan()` 变量遮蔽函数，抛 `ReferenceError`
- 表单扫描改为一次建立索引，17 个字段复用，页面大也不卡
- 草稿页「填入闲鱼」只填标题/描述/价格，表单页「填写整张表单」才填全部
- 智能模式只在「本地服务连不上」时才回落直连，避免同一个错误请求花两份钱
- 本地服务模式允许不填 Key（服务端可配环境变量）
- 下拉选项只在展开的下拉层里找，减少点错
- 上传图片优先选 `accept=image`、支持多选的商品图 input
- 版本号自动从 manifest 读取，面板不再显示错的 v0.5

## 加载方法

1. 浏览器打开 `edge://extensions/` 或 `chrome://extensions/`
2. 打开“开发人员模式 / 开发者模式”
3. 点击“加载解压缩的扩展”
4. 选择本目录（`闲鱼发布助手`）
5. 修改代码后点击扩展卡片上的“刷新”

## 使用步骤

1. 双击 `本地AI服务\启动闲鱼AI本地服务.bat`（也可设开机自启）
2. 打开闲鱼网页版发布页
3. 点击扩展图标打开面板（标题右侧版本号应为 0.8.0）
4. “AI 设置”里填入 DeepSeek API Key → 保存设置 → 测试连接
5. “草稿”页读取 JSON → AI 润色
6. “表单”页选图片 → 扫描表单（应显示已识别 N/17 个字段）→ 填写整张表单
7. 人工检查后手动点发布
