# 使用规范

本文是「拓咸助手 · 3D 打印模型闲鱼发布系统」的完整操作规范。
安装时请**对着本文件**和每个文件夹里的 `_安装说明.txt` 操作。

> 本次优化改了什么、怎么验证、怎么回滚：见 **[修复说明.md](修复说明.md)**。

## 2. 安装到浏览器（必看）

本系统有两个浏览器扩展，都要装：

- 采集扩展 → 装到浏览器，在 MakerWorld 用
- 闲鱼发布助手 → 装到浏览器，在闲鱼发布页用

### 2.1 第一次安装（以 Edge 为例）

1. 打开 Edge，地址栏输入并按回车：

```text
edge://extensions/
```

> Chrome 用户输入：`chrome://extensions/`

2. 打开页面右上角的开关：`开发人员模式`

3. 点击左上角按钮：`加载解压缩的扩展`

4. 在弹出的文件选择窗口里，选中**要安装的文件夹**：

```text
安装采集扩展：     E:\桌面\咸鱼助手\3D模型一键采集扩展
安装闲鱼发布助手： E:\桌面\咸鱼助手\拓咸助手\咸鱼自动发布3d打印模型系统\闲鱼发布助手（以你实际存放位置为准）
```

> 注意：要选到能直接看到 manifest.json 的那个文件夹，不能多选一层。
> 采集扩展的**日常加载路径**用 `E:\桌面\咸鱼助手\3D模型一键采集扩展`；
> 如果这个路径不存在，就选项目里的 `采集扩展\` 文件夹（两份代码是同步的）。

5. 安装成功后，扩展页会多出对应卡片，把开关打开（启用）。

### 2.2 之后更新代码

每次改了 `content.js / background.js / manifest.json` 之后：

1. 回到 `edge://extensions/`
2. 找到对应扩展卡片
3. 点击卡片上的「刷新」图标
4. **关闭并重新打开** 正在用的 MakerWorld / 闲鱼页面
   （旧页面可能还残留旧脚本，导致按钮没反应）

### 2.3 验证安装成功

```text
采集扩展：  卡片名称应显示“3D模型一键采集 v0.9.0-10图”
发布助手：  卡片名称应显示“闲鱼3D模型发布助手”
           打开面板后，标题右侧版本号应与卡片版本一致（自动读取 manifest）
本地AI服务：浏览器外启动，见第4节
```

## 3. 采集扩展使用（MakerWorld）

1. 确认已安装 `3D模型一键采集 v0.9.0-10图`（见 2.1）。
2. 打开 MakerWorld 模型页面。
3. 鼠标悬停在打印配置卡片上，等 `PLA | xxx g` 浮层出现（这一步决定能否抓到耗材克数）。
4. 按 `Alt + M`（只按一次，新版不会重复采集）。
5. 产物先进入浏览器下载目录，再由自动搬运进入：

```text
E:\桌面\咸鱼助手\3D模型一键采集扩展\信息储存\<时间文件夹>\
├── model_<模型ID>.json
├── screenshot_visible.png
└── images\image_01.png ~ image_10.png
```

> 如果没开自动搬运，双击 `采集扩展\启动自动搬运.bat`，或手动双击 `采集扩展\搬运一次.bat`。

### 3.1 采集成果说明

- 图片**已按设计图去重**：同一张图的 `w_1200 / w_1000 / w_400` 只保留最高清那张；
  一次最多保存 10 张不同画面。
- JSON 里除了标题/简介/图片链接，还有：
  - `guessed_filament_grams`：耗材克数候选（需要悬停打印配置）
  - `guessed_print_times`：打印时长候选（已过滤模型 ID 之类的垃圾数字）
  - `print_configs`：层高/填充等打印配置行
  - `published_at`：发布于日期
  - `file_links`：页面里如果有 3MF/STL/ZIP 直链会记录（没有则为空）
- 采集完成后右上角提示会显示：耗材 / 时长 / 图片 N/N / 截图 / 失败项；
  点一下提示条即可关闭。

## 4. 本地 AI 服务

启动方式（三选一）：

```text
方式A 手动：双击 本地AI服务\启动闲鱼AI本地服务.bat
方式B 开机自启：双击 本地AI服务\设置开机自启.bat
        （把“静默启动闲鱼AI服务.vbs”的快捷方式放进 Windows 启动文件夹，
          之后每次登录 Windows 会自动静默启动；双击 取消开机自启.bat 可撤销）
方式C 仅本次静默启动：双击 本地AI服务\静默启动闲鱼AI服务.vbs
```

启动成功的标志：窗口显示 `闲鱼 AI 本地服务 v0.6.0: http://127.0.0.1:8765`。

验证：闲鱼发布助手面板 → AI 设置 → 显示“本地服务在线 · deepseek-flash”。

> 修改 `local_ai_server.py` 后必须关闭旧窗口重新启动，否则仍用旧代码。

### 4.1 安全说明（v0.6.0 起）

- 服务只监听 `127.0.0.1`，外部网络访问不到。
- 请求必须带扩展专用的 `X-XY-Client` 请求头；普通网页要带这个头必须先通过跨域预检，
  而预检只对浏览器扩展放行，所以网页 / 沙箱 iframe（`Origin: null`）都会被拒绝。
- 你在浏览器里打开的普通网页调用会被拒绝（返回 `403 forbidden origin`），
  防止别的网站偷偷消耗你的 DeepSeek 额度。
- API Key 可以填在面板里，也可以只放在服务端环境变量 `DEEPSEEK_API_KEY`
  （这样面板里不填 Key 也能用本地模式）。
- 想换端口：设置环境变量 `XY_AI_PORT`，同时把面板里的「本地服务地址」改成新端口。
  如果 8765 被其它程序占用，服务会明确报错退出，而不会假装“已在运行”。

## 5. 闲鱼发布助手使用

1. 先启动本地 AI 服务（第4节）。
2. 打开闲鱼网页版发布页。
3. 点浏览器右上角扩展图标，打开面板。
4. 切到「AI 设置」：
   - 填 DeepSeek API Key（如果服务端已配置环境变量，本地模式可以不填）
   - 可编辑“AI 文案规则”
   - 点「保存设置」
   - 点「测试连接」，应显示“DeepSeek 连接正常”
5. 切到「草稿」：
   - 选择采集出的 JSON 文件（也可以选 `extract_model_info.py` 生成的 `.extracted.json`）
   - 选文案风格 → AI 润色
   - 看“人工确认”提示（会列出待确认项，比如耗材克数、图片授权）
6. 切到「表单」：
   - 选择图片（最多9张）
   - 扫描表单：应显示「已识别 N/17 个字段」（v0.8.0 修复了这个按钮）
   - 填写整张表单
7. **人工检查页面后，再手动点发布**。

### 5.1 两个「填入」按钮的区别

| 按钮 | 位置 | 会填什么 |
| --- | --- | --- |
| 填入闲鱼 | 草稿页 | 只填标题、描述、价格、原价 |
| 填写整张表单 | 表单页 | 分类 + 标题/描述/价格/原价 + 成色 + 发货 + 图片 |

### 5.2 草稿清洗规则（自动）

读取采集 JSON 时会自动：

- 去掉标题里的 ` - 免费 3D 打印模型 - MakerWorld` 后缀；
- 解码 `&amp;` 之类的 HTML 实体；
- 去掉简介开头的 `免费下载由…设计` 和后面的 `为我助力` 推广段；
- 如果读的是 `.extracted.json`，优先用里面的 `xianyu_title_safe` / `xianyu_copy_safe`。

## 6. AI 文案规则（重要）

在「AI 设置 → AI 文案规则」直接写中文规则，例如：

```text
【名称】保留原模型名称、IP 名称、系列名称和作者名称，不改泛化名。
【标题】优先用原模型名称，不超过30字，说明3D打印摆件/模型。
【卖点】突出收藏、展示、涂装练习、桌面摆件等实际用途。
【口吻】自然克制，像真实闲鱼卖家写的。
```

固定底线（不可解除）：
- 不虚构材质、尺寸、库存、发货时间
- 不自行添加“官方 / 正版 / 独家授权”等未提供声明
- 不绕过闲鱼平台限制与手机验证
- 不自动点击发布

> 模型能力：`deepseek-flash`（思考模式已关闭）。temperature 现在是真正生效的。

## 7. 数据与目录规范

- 采集结果实际存放：`E:\桌面\咸鱼助手\3D模型一键采集扩展\信息储存\`
- 项目归档：`data\collected\`（原始 JSON）、`data\processed\`（处理结果）
- 工具脚本用法：

```text
python 工具脚本\extract_model_info.py data\collected\model_xxx.json
python 工具脚本\generate_draft.py data\collected\model_xxx.json --out data\processed\草稿.md
```

### 7.1 搬运脚本参数

```text
双击 搬运一次.bat                                 搬一次（默认还会补一次历史缺图）
双击 启动自动搬运.bat                             常驻监控（默认每 3 秒）
python move_to_storage.py --repair                搬一次并补齐历史缺图
python move_to_storage.py --source D:\Downloads\模型发布信息采集 --target E:\数据\信息储存
python move_to_storage.py --watch --interval 5    自定义监控间隔
```

环境变量（可选）：

```text
XY_DOWNLOAD_DIR     浏览器下载目录（默认 用户目录\Downloads）
XY_COLLECT_TARGET   信息储存目录（默认脚本同级的 信息储存）
```

搬运出错会写到 `信息储存\_搬运错误.log`，方便事后排查。

### 7.2 兼容旧数据

- 旧版采集 JSON 里的 `hover_text_preview`、跨行垃圾时长，新版提取脚本都能兼容处理；
- 旧版图片链接的高低清重复，提取脚本也会去重；
- 旧提取结果（`.extracted.json`）字段不变，发布助手可直接读取。

## 8. 常见问题与自测

| 问题 | 处理 |
| --- | --- |
| 「扫描表单」没反应/报错 | v0.8.0 已修复；确认扩展页点过「刷新」，并重新打开闲鱼发布页 |
| 一次 Alt+M 出现两个时间文件夹 | v0.9.0 已修复（1.5 秒冷却）；确认采集扩展已刷新 |
| 在非 MakerWorld 页按 Alt+M/点图标没反应 | v0.9.0 起只在 MakerWorld 页面采集，图标会短暂显示红色「!」提示 |
| 面板显示服务未启动，但端口被占用 | 8765 被其它程序占用了；换端口（`XY_AI_PORT`）或关掉占用程序 |
| 采集后没有图片 | 确认鼠标悬停过打印配置卡片；确认自动搬运在运行；检查 `信息储存` 时间文件夹 |
| 采集图片有重复 | v0.9.0 已按设计图去重；旧数据可用新版 `extract_model_info.py` 重新提取 |
| 打印时间显示 `xxxx h` 这种怪数字 | v0.9.0 采集端已过滤；旧 JSON 用新版提取脚本重新跑一遍 |
| 插件按钮点了没反应 | 扩展页点「刷新」；关闭并重新打开闲鱼发布页 |
| 测试连接失败 | 先启动本地服务；检查 API Key；看底部错误提示 |
| 面板显示「本地服务未启动」 | 双击 `启动闲鱼AI本地服务.bat`；之前开过旧窗口就先关掉 |
| 服务报 `403 forbidden origin` | 说明请求来自普通网页，不是插件；重启服务并重载扩展即可 |
| 控制台报 emoji 编码错误 | 已修复；如果还遇到，设置 `PYTHONIOENCODING=utf-8` 再运行 |
| Edge 报 `__pycache__` | 删除扩展目录里的 `__pycache__` 后重新加载 |
| 改代码后不生效 | 本地服务重启；浏览器扩展点刷新；页面重新打开 |
| 找不到扩展卡片 | 确认选中了含 manifest.json 的文件夹，且开发人员模式已开 |

## 9. 打包与分发

- 打包前删除项目内所有 `__pycache__`。
- 压缩整个 `咸鱼自动发布3d打印模型系统` 文件夹即可；不要把 `信息储存`、`data\` 里的大图和采集数据一起打包。
- 分发给别人时提醒：自行申请 DeepSeek API Key；确认模型授权；把 `采集扩展\` 放到自己能加载的位置。
- 目录里的 `tests\`、`修复说明.md`、`requirements.txt` 可以一起分包，方便对方自测和排查。
