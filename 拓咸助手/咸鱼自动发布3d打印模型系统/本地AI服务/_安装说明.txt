========================================
 本地AI服务（DeepSeek 转发）v0.6.0
========================================

【这是做什么的】
把 DeepSeek 调用包一层：你的 API Key 不放进浏览器扩展，更安全。
闲鱼发布助手会调用 http://127.0.0.1:8765

【怎么启动】
方式A 手动：
  双击本目录的 启动闲鱼AI本地服务.bat
  看到“闲鱼 AI 本地服务 v0.6.0: http://127.0.0.1:8765”即成功，别关窗口。

方式B 开机自启（可选）：
  双击本目录的 设置开机自启.bat
  它会把“静默启动闲鱼AI服务.vbs”的快捷方式放进 Windows 启动文件夹，
  之后每次登录Windows会自动静默启动。
  想取消：双击 取消开机自启.bat。

方式C 仅本次静默启动：
  双击本目录的 静默启动闲鱼AI服务.vbs（只启动这一次，不写开机项）

【怎么验证】
浏览器里闲鱼发布助手 → AI设置 → 应显示“本地服务在线 · deepseek-flash”。
也可以在浏览器打开 http://127.0.0.1:8765/health 看返回。

【安全说明】
- 只监听 127.0.0.1，外部网络访问不到；
- 请求必须带扩展专用请求头 X-XY-Client；普通网页 / 沙箱 iframe（Origin: null）调用会返回 403；
- 如果 8765 被其它程序占用，服务会明确报错退出，不会假装“已在运行”；
- API Key 可以填在面板里，也可以用环境变量 DEEPSEEK_API_KEY。

【注意】
- 修改 local_ai_server.py 后，要关掉旧服务窗口重新启动。
- 换端口：设置环境变量 XY_AI_PORT，同时改面板里的“本地服务地址”。
- 模型已改为 deepseek-flash，并关闭了思考模式（更快、更省 token）。
